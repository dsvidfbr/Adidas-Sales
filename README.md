📊 Adidas Sales Performance Dashboard (2020–2021)

Este projeto apresenta um dashboard analítico de performance comercial da Adidas, com foco em vendas por produto, região, tempo e varejista.
Diferente de análises baseadas em dados prontos, neste projeto realizei todo o pipeline de dados, desde a extração até a modelagem final para visualização.

🛠️ Pipeline de Dados (ETL)

1. Extração

Coleta dos dados brutos de vendas

Consolidação de múltiplas fontes em uma base única

2. Transformação

Limpeza e padronização de campos

Tratamento de valores nulos e inconsistências

Criação de métricas de negócio:

Receita total

Unidades vendidas

Ticket médio

Crescimento MoM

Modelagem para análise dimensional

3. Carga

Estruturação do modelo para consumo em ferramenta de BI

Otimização para performance analítica

📎 Sobre o Projeto

Este projeto foi desenvolvido como estudo prático de análise de dados e construção de soluções completas de BI, simulando um cenário real de tomada de decisão empresarial.
